    Fix the failures people and agents hit most often with Kuyfi.

    Still stuck?

    Open an issue on GitHub with OS, Node version, Contract ID (Testnet), and the exactScanError.code or CLI stderr. Never paste secret keys.

    Install / CLI

    SymptomFix
    kuyfi not found after npm installConfirm Node ≥ 20; reinstall global package; check npm prefix bin is onPATH.
    PowerShell blocks kuyfi.ps1Use kuyfi.cmd / npm.cmd, or set CurrentUserRemoteSigned. See Installation.
    invalid Contract IDMust match C + 55 A-Z0-9 characters — no lowercase.
    Exit 0 but findings are CRITICALNot a bug. Exit codes mean tool success/failure, not severity. Parse JSON summary / findings in CI. SeeCLI.

    Scanner errors

    CodeMeaningWhat to try
    CONTRACT_NOT_FOUNDRPC has no WASM for that IDConfirm Testnet deploy; wait for indexing; check typos
    RPC_UNAVAILABLENetwork / endpoint downCheck connectivity to soroban-testnet.stellar.org; retry
    XDR_ALIGN_FAILUREcontractspec parse failedContract may lack a standard contractspecv0 section (non-SDK or exotic build)
    UNKNOWNUnclassified failureCapture full message; open issue

    Chaos Monkey

    SymptomExplanation
    Lots of PRECONDITION / few findingsNormal: ephemeral account is not an authorized signer. Noise is filtered from the findings list on purpose.
    Friendbot / funding fails3 retries then throw. Testnet faucet hiccup — retry later; check RPC health. Headless surfaces as Audit failed: Ephemeral keypair funding failed…
    Many TIMEOUTsPoll window is 20 × 1s after send. Network congestion or slow confirmations — rerun; treat as LOW / inconclusive.
    Function skippedUnresolved UDT or empty param list for that family — seeVectors.
    “Is my contract safe? Zero findings.”No. Absence of findings ≠ absence of vulns. Black-box coverage is partial.

    Reports

    • Refusing to overwrite existing file: kuyfi-report-… — rename or delete the existing report, then re-export (writes use wx).
    • JSON and PDF disagree? They shouldn’t — same reportId. Re-export from one run.
    • Missing explorer URL? Simulation-only classification never broadcasts.
    • CI parse errors? Gate on schemaVersion === "1.0.0" — see schema.

    TUI

    • Chaos Monkey blocked with “Run OSINT Scanner first…” — expected. Scan in this session before opening Chaos Monkey.
    • System Logs looks “always green” — LogsScreen is static status text, not a live RPC diagnostic stream.
    • Terminal too small (< 70 cols or < 20 rows) → TooSmallNotice; resize and continue.

    Paid scan server

    StatusMeaning
    400INVALID_CONTRACT_ID before paywall — fix the ID shape
    402Complete x402 payment (Local402 client quote flow)
    404 / 422 / 502 / 500Scan failed after auth — body { "error": "<ScanErrorCode>" };not settled (payer not charged)
    • PAY_TO missing / secret key → use a public G… only; server exits 1 without it.
    • Chaos Monkey over HTTP? Intentionally unsupported.
    • Full contract → Paid scan API.
