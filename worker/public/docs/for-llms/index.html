    Do not confuse with MDX

    MDX = Markdown + JSX components (docs UI authoring). It is not “Markdown for machines.”

    Kuyfi exposes Markdown for Agents: plain Markdown viaCopy as Markdown, /docs/md/<slug>.md, andllms.txt — the Cloudflare-style pattern.

    Preferred ingestion order
    1. https://kuyfi.vercel.app/docs/llms.txt — compact index
    2. https://kuyfi.vercel.app/docs/llms-full.txt — full manual
    3. https://kuyfi.vercel.app/docs/md/<slug>.md — per-page Markdown (or use Page options → Copy as Markdown)
    4. HTML pages only for human navigation / diagrams

    Full setup guide (terminology, curl examples, page index): Agent setup.

    One-paragraph project card (copy)

    Kuyfi (@kuyfi/kuyfi, CLI `kuyfi`) is an open-source black-box security terminal for Soroban smart contracts on Stellar Testnet. Given a Contract ID, it fetches on-chain WASM, reconstructs the attack surface from contractspecv0, runs type-aware Chaos Monkey fuzzing (simulate-first, optional Testnet broadcast with ephemeral Friendbot keys), classifies DiagnosticEvent traces into a six-signal taxonomy, and exports a SecurityReport as JSON/PDF. It is not a formal audit. Testnet only. Never fuzz unauthorized contracts.

    Install copy for agents

    $ npm install -g @kuyfi/kuyfi

    Then run kuyfi · Before the Breach.

    Safe agent playbook

    1. Confirm the user owns the Contract ID or has written authorization.
    2. Confirm network is Testnet (Kuyfi hardcodes Testnet RPC).
    3. Prefer headless: kuyfi <ID> --json for structured output.
    4. Treat POTENTIAL_VULN as investigate-first; never rewrite findings into “confirmed CVE”.
    5. Do not invent Mainnet support, SaaS dashboards, or MCP tools that are not shipped.
    6. Ingest plain Markdown / llms.txt — never assume MDX is the agent format.
