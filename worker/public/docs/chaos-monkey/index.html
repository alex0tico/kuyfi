    Chaos Monkey

    Page options
    View as Markdown Agent setup

    Type-aware fuzzing for Soroban — not random dumb bytes. Simulate first; broadcast only when preflight proceeds.

    On this page

    1. Execution model
    2. Type-correct ≠ valid
    3. Five families
    4. Session lifecycle
    5. Friendbot & keypairs
    6. Invoke / poll
    7. Modules
    8. Fixtures

    Full attack-label catalog (math labels, admin patterns, sequences): Attack vectors reference.

    Real Testnet transactions

    Vectors whose simulation succeeds are signed with an ephemeral Friendbot-funded keypair and submitted on-chain. Keypairs are never written to disk or logged.

    Execution model

    vector → simulate (preflight)
           ├─ simulation fails    → classify from diagnostic events (nothing sent)
           └─ simulation succeeds → sign → broadcast → poll → classify

    Many findings are therefore classified without an on-chain transaction. Only broadcast txs appear in verification samples and explorer links.

    Design constraint

    Type-correct ≠ semantically valid. A random Address is not a funded account, token, or authorized signer. Kuyfi classifies conservatively and treats ambiguity as ambiguity — see Findings.

    Five vector families

    FamilyModuleWhat it probesexpectedToFail
    Math / boundaryfuzzer_math.tsPer-type boundaries (ZERO, MAX_I128, empty/oversized bytes/strings, recursive UDT fields one-at-a-time).false
    Authorizationfuzzer_access.tsUNAUTHORIZED_CALL, REINIT_ATTACK,SELF_CALL_ATTACK, UNAUTHORIZED_ADDR_CALL.true
    Fee / BPSfuzzer_fee.tsBPS_* + type max on fee-shaped numeric params.false
    Liquidity ratiofuzzer_liquidity.tsPaired extremes on swap/reserve-shaped functions.false
    Call orderingfuzzer_call_order.tsSame function twice: reinit / withdraw / claim sequences (once per session).false

    Session lifecycle (runChaosMonkey)

    1. Generate ephemeral keypair + Friendbot fund + on-chain confirmation.
    2. Connect Testnet RPC.
    3. Per discovered function, in this order: math → access → fee → liquidity (each self-gates on name/params).
    4. Once per session (after all per-function work): call-ordering candidates.
    5. Aggregate ChaosReport —SECURE / PRECONDITION_FAIL filtered from findings list, kept in counters.

    Progress strings include stages like generating the ephemeral keypair and per-function family lines (math / access / …) via the progress callback.

    Friendbot & ephemeral keypairs

    Module keypair_factory.ts:

    • Friendbot URL: https://friendbot.stellar.org/?addr=
    • 3 funding retries with backoff between attempts
    • After HTTP OK: poll getAccount up to 10 × 1s for on-chain confirmation
    • Failure after retries → throwEphemeral keypair funding failed after 3 retries: …(headless surfaces as Audit failed: …)
    • Keys never persisted to disk or logged

    Invoke / poll constants

    Module router.ts — invokeContract() never throws; always returns typed InvokeResult:

    • BASE_FEE = '100'
    • TX_TIMEOUT_SECONDS = 30 on the built transaction
    • Poll getTransaction: 20 × 1000ms → TIMEOUT
    • broadcasted is true only when sendTransaction was called successfully. A hash may still exist on SEND_ERROR (local envelope hash) with broadcasted: false — check both fields.

    Key modules

    • keypair_factory.ts — ephemeral keys, never persisted
    • type_gen.ts — baseline + attack ScVals from XDR types
    • router.ts — invokeContract() lifecycle
    • trace_analyzer.ts — AUTH / CONTRACT / CONTEXT / OBJECT / STORAGE / WASM_VM / …
    • result_parser.ts — maps traces → VulnerabilitySignal + Severity
    • reporter.ts — KYF-NNN IDs, verification transaction sample

    Fixtures

    Repo test-fixtures/ includes an intentionally vulnerable access-control contract and a composite UDT fixture for controlled Testnet demos — not production code.

    • intentionally-vulnerable-contract — set_admin_value withoutrequire_auth vs secure twin; name chosen to match admin patterns.
    • composite-udt-fixture — nested structs/unions for recursive type_gen coverage.
