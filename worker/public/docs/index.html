    KUYFI

    Page options
    View as Markdown Agent setup

    Black-box security for Soroban.

    Kuyfi analyzes deployed Soroban contracts from their on-chain interface, so you can inspect their attack surface, exercise inputs and review execution traces without requiring the source code.

    $ npm install -g @kuyfi/kuyfi

    Then run kuyfi · Before the Breach.

    VIEW ON GITHUBQUICKSTARTMCPConnect
    What Kuyfi is

    An automated black-box security terminal for Soroban. It is the layer before a formal audit — catch obvious surface issues on Testnet so auditors start from a cleaner baseline. It is not a certification and does not replace Ottersec, Veridise, CoinFabrik, or peers.

    [ 03 · PIPELINE ]

    From Contract ID to execution evidence.

    The OSINT Scanner maps functions, arguments and user-defined types first. Chaos Monkey then generates type-aware inputs, simulates execution and classifies the resulting traces. When an execution reaches the network, Kuyfi preserves the available transaction evidence alongside the report.

    1. 01INPUTContract ID
    2. 02OSINT SCANNERFetch deployed WASM / specification
    3. 03RECONSTRUCTReconstruct attack surface
    4. 04CHAOS MONKEYGenerate type-aware vectors
    5. 05SIMULATESimulate and classify
    6. 06OUTPUTJSON / PDF report

    Why it exists

    Formal audits need source, scheduling, and budget. Anyone can invoke a deployed Soroban contract; not everyone has its Rust source. Kuyfi starts from what is actually observable on-chain: WASM bytecode, the contractspecv0 section, and runtime behavior under simulation and Testnet calls.

    run Kuyfi → fix obvious issues → submit to a formal audit with a cleaner baseline

    What you get

    • OSINT Scanner — reconstruct functions, params, and UDTs from a Contract ID alone.
    • Chaos Monkey — type-aware fuzzing (math, auth, call-order, fee, liquidity), simulate-first, broadcast only when preflight succeeds.
    • SecurityReport — one canonical object, exportable as JSON and PDF with execution evidence (hashes, ledgers, explorer URLs).
    • TUI + headless CLI — same engine for interactive and CI use.
    • Paid scan API — optional x402/Local402 endpoint for read-only scans (Chaos Monkey stays local).

    Hard constraints

    • Stellar Testnet only — RPC is hardcoded to https://soroban-testnet.stellar.org.
    • No private keys persisted — ephemeral Friendbot-funded keypairs in memory.
    • Findings are signals, not proven exploits.
    • Only test contracts you own or are authorized to test.
