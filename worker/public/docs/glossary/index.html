    Product

    Kuyfi
    Open-source black-box security terminal for Soroban. Tagline: Before the Breach.
    Black-box
    Testing without source: only WASM, contractspecv0, and observable runtime behavior.
    SecurityReport
    Canonical JSON document (schemaVersion 1.0.0) also rendered as PDF. One object per audit run.
    Finding
    A classified signal that passed noise filters. A lead for humans — not a CVE or formal audit claim.

    Stellar / Soroban

    Contract ID
    Deployed contract address: C + 55 base32 chars. Validated by/^C[A-Z0-9]{55}$/.
    WASM
    WebAssembly bytecode published on-chain for the contract.
    contractspecv0
    Custom WASM section listing exported functions, parameter types, and UDTs (Soroban SDK contracts).
    UDT
    User-defined type: struct, enum, or union recovered from the spec.
    ScVal
    Soroban XDR value used as a function argument.
    DiagnosticEvent
    Structured host/contract trace events returned by RPC for simulations and transactions — primary evidence for Kuyfi’s classifier.
    Friendbot
    Testnet faucet that funds ephemeral accounts Kuyfi creates in memory.
    Testnet
    Only network Kuyfi talks to (https://soroban-testnet.stellar.org). Mainnet is out of scope in v0.1.0.

    Kuyfi engine

    OSINT Scanner
    Read-only phase: fetch WASM, parse spec, emit attack surface.
    Chaos Monkey
    Type-aware fuzzing campaign across five vector families.
    Vector
    One attack attempt (named, e.g. amount::MAX_I128 orUNAUTHORIZED_CALL).
    Baseline value
    Neutral type-correct ScVal held constant while one parameter is mutated.
    Preflight / simulate
    Dry-run before broadcast. Failed simulations are classified without sending a transaction.
    x402 / Local402
    Payment protocol stack used by optional kuyfi-server to charge per OSINT scan (e.g. priced in CLP → USDC).

    Signals (short)

    • SECURE — expected / benign outcome (filtered from findings list)
    • PRECONDITION_FAIL — missing setup / structural auth (filtered)
    • UNEXPECTED_ERROR — inconclusive failure
    • POTENTIAL_VULN — security signal needing review
    • UNCONTROLLED_PANIC — robustness trap
    • TIMEOUT — poll window miss
